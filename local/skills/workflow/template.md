## A9. 分段提示词模板（本机 H3）

A9 只定义**最终交付外壳**，不改变 A2–A8 的任何执行逻辑；与 A2–A8、A11–A12 冲突时以执行规则为准。PART A 其他条款中提到的 A9.1 / A9.2，一律指本节 H3 模板。

```text
═══════════════════════════════════════════
G0N｜Batch X / 段 N ｜目标模型：本机 H3（h3PikaFast / h3Pika）｜本段时长：Xs（4–15 整数）｜全局时间：MM:SS–MM:SS
生成方式：text / 参考模式 / 首帧 / 关键帧｜画幅：16:9｜generateAudio：开 / 关
═══════════════════════════════════════════

## 资产标识
（同 A4：涉及角色 / 场景 / 关键道具，及其出镜状态；只列本段真实出现的）

─────────────────────────────────────────
【正式提示词】（以下整体写入视频节点）

@首帧 {{ref a}}            ← 仅关键帧方式；其余方式删去这几行
@关键帧 1.5s {{ref b}}
@尾帧 {{ref c}}
<Audio 1>: fully_copy      ← 仅在用配音锚定口型时保留

一句话风格开场：画风 / 质感 / 时代 / 色调。

## 人物空间关系
{{ref N}} 是 ……（每个主体只定义一次：身份 + 外观锚点 + 世界坐标 + 画面坐标）
道具：在谁手里、哪只手、握哪端、哪端接触。

## 镜头 N-1｜00:00–00:XX｜XXs｜主体 + 景别 + 角度
摄影机与构图：……
动作时间轴：0.0–1.2s …；1.2–2.5s …（与关键帧时间对齐）
接触规则：只有……接触……；其余部位保持距离。
物理：……

## 光线
（主光源方向 + 曝光逻辑 + 与前段的连续性）

## 声音
环境声；对白写成  角色名：“原文”（逐字，不改写，时长符合 A3.2）；音乐按用户要求。

## 正向锁
（人物绝对位置 / 道具持有 / 视线 / 连续状态 / 本镜不该出现的人物）

## 文字锁
无字幕、无屏幕文字、无水印；道具无标签。
```

**H3 写法要点**
- `{{ref N}}` 保留原样，由宿主按引用顺序转换，不要手写 `<Picture N>`；同一张图在同一段内只承担一个用途。
- 时长按整数秒填；动作节拍总和不超过本段时长，结尾留出约 0.5 秒余量。
- 多人画面逐一点名，否则“替换穿黑衣的人”会连带重画其他深色衣服的人；人群要稀疏、道具要大而少。
- 本段与下一段连续时，下一段首帧用本段最终采用结果的尾帧截图，而不是重新生成。
